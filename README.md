# 命理知识库入口

这个仓库用于给 Monica / 自定义技能读取命理文档。

为避免工具在读取时因为路径猜错而出现 `404`，根目录已经提供了稳定入口文件和常用主题文件。
调用时优先读取根目录文件，不必手动拼接 `bzxs/`。

推荐读取顺序：
1. 先读 `知识库索引.md`
2. 根据问题主题选择对应文件
3. 如果问大运、流年、今年、明年，优先读 `DaYun.md` 或 `大运.md`
4. 如果问格局、身强身弱、喜用神，优先读 `GeJu.md`、`XiJi.md`、`日主强弱.md`

常用主题映射：
- 整体命盘、格局、命格：`GeJu.md`
- 日主强弱、身强身弱、喜用神：`日主强弱.md`、`XiJi.md`
- 大运、流年、今年、明年：`DaYun.md`、`大运.md`、`流年.md`
- 财运、赚钱、偏财、正财：`CaiYun.md`
- 事业、工作、升职、官运：`ShiYe.md`
- 感情、婚姻、对象、桃花：`QingGan.md`
- 健康、身体、疾病：`JianKang.md`
- 父母、兄弟、子女、六亲：`LiuQin.md`
- 神煞、贵人、桃花、驿马：`ShenSha.md`
- 基础术语、五行、十神、天干地支：`JiChu.md`

使用规则：
- 优先读取根目录文件。
- 不要猜测不存在的文件名。
- 未命中时，先回到 `知识库索引.md` 重新选择文件。
